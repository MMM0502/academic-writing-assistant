# Specification

## 文稿规整

### Scenario: 处理单篇文稿

- Given 用户上传可读取的 DOCX、PDF、TXT 或 MD 文件
- When 用户选择引用规范并点击开始规整
- Then 系统提取正文和参考文献，输出统一编号的结果
- And 系统保存一条可下载的处理记录

### Scenario: 输入不合法

- Given 用户未上传文件、上传空文件或上传不支持的扩展名
- When 用户提交
- Then 系统返回中文错误信息，不创建处理记录

### Scenario: 检测风险

- Given 参考文献存在重复标题或未识别年份
- When 系统完成规整
- Then 结果中包含可读的风险提示

## 综述生成

### Scenario: 批量生成综述

- Given 用户上传一篇或多篇可读取文献
- When 用户提交主题和文献
- Then 系统输出研究概述、主题脉络、研究不足和参考文献清单
- And 输出关键词、年份范围和处理引擎

### Scenario: 大模型增强失败

- Given 大模型未配置、超时或返回无效结果
- When 系统生成综述
- Then 系统使用本地规则引擎完成响应，不向用户暴露内部异常

## 工作区

### Scenario: 查看历史

- Given 系统存在已完成处理记录
- When 用户打开处理记录
- Then 系统按时间倒序显示标题、类型、时间和下载入口
